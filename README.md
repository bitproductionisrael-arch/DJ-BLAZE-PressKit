# DJ BLAZE — Official Press Kit

Independent, mobile-friendly electronic press kit for DJ BLAZE (Amit Mike Rov), based in Koh Samui, Thailand.

## Included

- `index.html`: standalone HTML landing page, biography, credits, media links and bookings.
- `assets/dj-blaze-live.jpg`: original live-performance photograph extracted from the press kit that was used for venue outreach.
- `DJ_BLAZE_Press_Kit.pdf`: PDF press kit and artist CV previously sent to venue contacts.

## Publish the independent website

The repository is **public** by choice. This press kit is separate from the Gematria project and will not be linked from or embedded in that project's homepage.

To enable a public GitHub Pages URL:

1. Open the repository's **Settings** > **Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select **main** and **/(root)** and click **Save**.
4. Wait for the Pages deployment to finish. The site URL should then be: https://bitproductionisrael-arch.github.io/DJ-BLAZE-PressKit/

Opening or publishing this separate repository does not modify the user's main website. The public GitHub Pages URL must be enabled in the repository settings; a public GitHub repository alone is not a deployed site.
